Privacy Policy
Last updated: February 25, 2026

1. Introduction

Portavon ("we", "our", "the app") is a mobile application for managing Docker containers through a Portainer server. Your privacy is important to us. This policy explains what data the app handles and how.

Summary: Portavon does not collect, store, or share your personal data with anyone. All data stays on your device.

2. Data Stored Locally on Your Device

Portavon stores the following data only on your device using secure storage:

  • Server URL — The address of your Portainer server
  • Authentication token — JWT token received from your server for API access
  • App preferences — Theme selection (dark/light), display settings

This data never leaves your device and is not accessible to us or any third party.

3. Data We Do NOT Collect

  • Personal information (name, email, phone number)
  • Location data
  • Device identifiers or advertising IDs
  • Usage analytics or behavioral data
  • Crash reports or diagnostics
  • Your Portainer username or password (only the JWT token is stored)
  • Container data, logs, or server information

4. Network Communication

Portavon communicates only with the Portainer server URL that you provide:

  • Connects directly to your server via HTTPS
  • Does not connect to any analytics, advertising, or tracking services
  • Does not send data to our servers (we have no servers)
  • Does not make any network requests other than to your specified Portainer server

5. Third-Party Services

Portavon does not integrate with any third-party services such as Google Analytics, Firebase, advertising networks, social media SDKs, or crash reporting tools.

6. Data Security

  • Authentication tokens are stored using Android Keystore (encrypted secure storage)
  • All network communication uses HTTPS encryption
  • No sensitive data is stored in plain text

7. Data Deletion

You have full control over your data:

  • Logging out — Clears authentication token and server data
  • Clearing app data — Android Settings → Apps → Portavon → Clear Data
  • Uninstalling the app — Removes all locally stored data completely

8. Children's Privacy

Portavon is a server management tool designed for adults. The app is not intended for use by children under 13 years of age.

9. Advertising

Portavon contains no advertisements and does not integrate with any advertising networks.

10. Permissions

INTERNET — Required to communicate with your Portainer server. No other permissions are requested.

11. Changes to This Policy

We may update this privacy policy from time to time. Changes will be posted on this page with an updated revision date.
