2. What Portavon Does

Portavon is a client for the Portainer API. It connects directly from your device to a Portainer server (Community or Business Edition) at the URL you enter and lets you view and manage the Docker resources that server controls, including:

  • Containers — list, start, stop, restart, kill, pause, remove, create and duplicate containers; view details, real-time logs and resource statistics; run commands and open an interactive console
  • Stacks — deploy stacks from text, an uploaded file or a Git repository; edit, start and stop them
  • Images, volumes and networks — pull, inspect, remove and prune them
  • Environments, users, teams, roles, registries, templates, tags and webhooks — manage them to the extent your Portainer account permits
  • System — view Docker and Portainer status and events, change Portainer settings, and create or restore Portainer backups
  • Home screen widget — shows a summary of your containers and refreshes in the background roughly every 15 minutes

Portavon does not include, host or operate a Portainer server, Docker host or any other infrastructure. You need your own Portainer server, or access to one, to use the app.
